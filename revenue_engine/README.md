# Amravati Revenue Engine

Production-oriented lead-to-revenue operating system for local businesses in Amravati.

Components: FastAPI backend, PostgreSQL/SQLite support, Redis-ready workers, React dashboard migration area, UPI order/payment workflow, PDF invoice support, Telegram telemetry integration point, Windows EXE packaging, Docker Compose, security and deployment documentation.

Safety defaults: outreach is dry-run by default; payment verification is separate from QR generation; never commit credentials.

See docs/SETUP.md, docs/SECURITY.md and docs/PAYMENTS.md.
